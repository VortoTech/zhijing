## 设计转译结论

本轮是视觉语言转译，不是对参考海报进行像素复刻：保留知镜现有的知乎内容和交互，将参考案例的高对比蓝、黑、白体系应用到首页、观点桌面和知乎现场。首页进一步收束为“看山啊”单一沉浸式入口。

没有剩余可执行的 P0、P1 或 P2 问题。

- 字体与排版：继续使用现有中文标题与正文层级，扩大黑白对比和蓝色重点词，避免为了追随英文海报字体而损伤中文可读性。
- 间距与布局：首页改为白底全屏主视觉，CTA 直接进入知乎现场；观点桌面保留 8 席环桌构图；知乎现场保留左右分歧结构。
- 色彩系统：背景使用冷白与淡蓝，核心入口使用近黑，交互强调统一为电光蓝；原先的暖米色、墨绿和橙色语义已收束到蓝、黑、白系统。
- IP 保护：8 个看山 IP 沿用原始彩色 PNG，没有使用灰度、色相旋转或饱和度滤镜；浏览器计算样式中仅保留 `drop-shadow(...)`。
- 场景资产：桌面采用蓝灰化材质并强化蓝色桌沿，8 把座椅保持中性灰白且按真实围桌方向排列，不与 IP 抢色。
- 文案内容：主题、知乎原话、评论反驳、8 种语气和 AI 免责声明保持不变。
- 响应式：首页在窄屏转为底部文案层并调整主视觉焦点；观点桌面在 390 × 844 下保持两列人物布局。

## 信息架构与交互验收

- 首页只提供一个“开始体验”主按钮，直接进入知乎现场，减少比赛演示前的选择成本。
- 观点桌面与知乎真实话题模块可互相切换，也可通过“返回”按钮回到首页。
- 8 个 IP 均可选择，选中态、角色标签和下方回应同步更新。
- 输入追问并发送后，8 个角色同时出现 iOS 风格三点思考气泡，完成后返回所选语气的回答。
- 语音按钮保留 `SpeechRecognition / webkitSpeechRecognition` 接入，并提供不支持时的键盘输入退路。
- 知乎现场保留真实话题样本、原回答、评论区反驳、来源链接和搜索能力。
- 中英文切换覆盖首页、知乎现场、观点桌面、来源说明、“我的知乎”和聊天状态；真实知乎标题、答主原话与评论保持原文。
