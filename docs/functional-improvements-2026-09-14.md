# 知镜第一轮功能完善 · 2026-09-14

以下为功能阶段的历史记录；后续 UI 适配与独立 PR 交付见 [最新交接文档](handoff-2026-09-14.md)。

本轮基于本地 `codex/competition-ui-i18n` 分支的 `9ff2eec`，直接修改原程序。用户要求保持现有 UI、完善搜索／登录／收藏体检／答主视角／条件选择／找同路人，并明确要求等待指令后才提交或推送。本轮没有 commit、push、创建或更新 PR、合并、部署。

`public/style.css` 与全部视觉素材没有改动。沿用现有卡片、提示区、条件证据展开和来源抽屉；只调整功能状态与必要文字，未改版。交接记录作为问题线索使用，其中旧授权或建议不作为本轮操作指令。

## 新增或调整的接口约定

- `/api/advice` 的 `message` 只包含用户本次原文；新增 `tone`、`language`、`focus`（`recordId`、`kind`、`text`、可选 `commentIndex`）。服务端语气使用白名单；`focus` 必须匹配服务端证据目录，伪造内容不会传入模型作为选中原话。
- `/api/my/checkup` 仍使用 `{source: "collections" | "contents"}`；可传 `refresh: true` 重试未完成的缓存结果。响应新增总体 `incomplete`、`failedSearches` 与逐项 `incomplete`；搜索失败项为 `search_failed`。当前重试会重新运行该种体检的本轮样本，尚未做到只重跑失败单条。
- `/api/usage` 是当前进程的任务次数预算，**不是知乎平台余额**。`scope: "process"`，`upstreamQuota: null`；重启清零，不支持多实例共享预算。实时分析或体检每次计一，陪伴补搜每次计一，缓存命中不扣次数；不代表实际 API 请求数、token 数或金额。

## 验证边界

真实知乎 OAuth、收藏及本人内容读取、上游额度、真实模型语义质量和 PostgreSQL 持久化未在本轮联调；在线与账号流程使用模拟服务。未做真机软键盘验收。新增已有回答自述会改变模型候选材料，仍需独立语义样本评估，不能把工程回归通过解释为同路人判断准确率提升。

复现：先 `npm ci --ignore-scripts`，运行 `npm run check`、`npm test`；启动 `npm start` 后执行 `npm run smoke`。可选 `npm run test:browser` 需要本机 Playwright 与 Chromium，或通过 `ZHIJING_PLAYWRIGHT_MODULE`、`ZHIJING_CHROMIUM_PATH` 指向已有运行时。浏览器脚本启动独立临时服务，默认不会访问真实上游，截图保存在 `output/browser-regressions/`。
