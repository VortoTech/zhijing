## 本地运行与配置

要求 Node >=22.9。克隆后切换本次分支，在仓库目录执行：

```sh
npm ci
npm start
```

默认访问 `http://127.0.0.1:4318/`。不填凭据可阅读仓库自带示例。`/#home`、`/#table`、`/#mine` 对应首页、观点桌面、我的知乎。此前开发预览使用 57409 端口，该端口不是部署约定。

需要在线能力时，将 `.env.example` 复制为 `.env.local` 并按项目授权配置；不要提交实际密钥：

- 实时检索：`ZHIHU_ACCESS_SECRET`、模型服务配置和 `ZHIJING_ENABLE_PILOT`。
- 模型：`AI_BASE_URL`、`AI_API_KEY`、`AI_MODEL`，必要时设置 `AI_EXTRA_BODY`。
- 登录：`ZHIHU_OAUTH_APP_ID`、`ZHIHU_OAUTH_APP_KEY`、`ZHIHU_OAUTH_REDIRECT_URI`；回调必须与平台登记完全一致。
- 任务预算：`ZHIJING_LIVE_DAILY_LIMIT` 默认 200，`ZHIJING_ADVICE_DAILY_LIMIT` 默认 600。
- 持久化及生产部署继续参考现有部署文档与 `src/store.mjs`，本轮未执行数据库迁移或生产操作。

## 尚未验证与当前限制

1. 真实知乎 OAuth、真实收藏／本人内容及付费模型没有在本轮重新联调；模拟流程通过不能视为生产验收。
2. 尚未做真实手机软键盘、浏览器安全区、语音权限与麦克风输入测试，也未验证生产 PostgreSQL 重启／并发场景。
3. 预算按当前服务进程统计任务次数，北京时间次日重置，重启清零；不支持多实例共享，不代表上游平台余额。
4. 体检的“重试未完成”目前刷新对应类别的整批内容，尚未做到只重试失败单项。
5. 新样式叠加在旧 CSS 上；虽然已覆盖主要尺寸，后续应收敛为统一组件样式。
6. 来源可能只有摘要及少量精选评论，不能声称读取了完整知乎评论区；模型归纳、异议与同路人匹配仍需持续人工评估。
7. 未接入官方热榜、问题发现、知识库 RAG、PDF／PPT、平台额度查询等新能力；需要先确认实际接口契约和授权。
